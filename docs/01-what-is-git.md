# What is Git?

Git is a **version control system** — a tool that tracks changes to files over time. It lets you:

- See the full history of every change ever made to a project
- Go back to any earlier version
- Work on new ideas without breaking what already works
- Collaborate with others without overwriting each other's work

## Why version control?

Imagine you're writing an essay and you save copies as `essay_v1.docx`, `essay_v2.docx`, `essay_FINAL.docx`, `essay_FINAL_real.docx`. Git solves this problem properly — it stores the history inside the project folder itself, so you always have one file but complete history.

## Git vs GitHub

**Git** is the tool that runs on your computer and tracks changes.

**GitHub** (and GitLab, Bitbucket, etc.) are websites that host a copy of your Git repository online, making it easy to share and collaborate.

You can use Git without GitHub, but you can't use GitHub without Git.
